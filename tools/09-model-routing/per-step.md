## How to choose

| | Low volume | High volume |
| --- | --- | --- |
| **Costly if wrong** | The best model you can rent | The best model, plus a person. This is where the test set earns its keep |
| **Cheap if wrong** | Whatever passes. Don't over-think it | The cheapest that passes. Small or local models |

Data rules beat cost, every time. If people are cheaper for a step, say so and don't deploy there.
