# Delete, automate, augment · sorting sheet

**Workflow:**

For each step, ask what happens five minutes before and after it. Then choose one pile.

- **Delete.** It exists because of a system boundary, an old incident or a report nobody reads. Remove it. No software needed.
- **Automate.** Routine, checkable and worth doing. A candidate for an agent, starting at Observe (tool 6).
- **Augment.** It carries judgement, or it's how people learn (tool 8). Software drafts, a person decides.
