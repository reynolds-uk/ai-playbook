# The grades and the gates

Set the criteria in writing before anything is measured against them.

## In plain terms

Autonomy isn't a setting you switch on. It's a grade that a piece of software earns against criteria published in advance, and loses automatically when its results slip. There are four grades: it watches, it recommends, it prepares, it acts. A grade earned that way is a control an auditor can test. Autonomy that was assumed is a liability nobody has priced.

## What to ask for

The written criteria for each grade, dated before the first measurement, and the list of promotions and demotions. If nothing has ever been demoted, be suspicious of the promotions.

The reasoning is in [Earned autonomy](https://ai.valuecreator.io/read/control#earned).
