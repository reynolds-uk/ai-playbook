# The grades and the gates · criteria

**Workflow:**
**Published on (before any measurement):**
**Owner:**

Every agent starts at Observe, whatever the vendor says it can do. Fill in your own thresholds.

| Grade | What the agent does | To move up, it must show | Your threshold |
| --- | --- | --- | --- |
| Observe | Works the live queue beside a person. Output held back and compared | Agreement with the person's decision, over enough cases to mean something | Agreement ___ % over ___ cases |
| Recommend | Drafts. The person decides | Acceptance above threshold, and an override analysis showing overrides are not systematic | Acceptance ___ % · systematic overrides under ___ % |
| Prepare | Completes the work. A person approves without material changes | Sustained approval without changes, and a clean test-set run | ___ % without changes for ___ weeks · test set ___ % |
| Act | Acts alone, with a supervisor's signature and a way to reverse it | Kept only while the evidence holds. Re-confirmed on every test-set run | |

## Automatic demotion, back to Observe

- Drift against the test set past ___ %
- Exception rate above ___ %
- Entry into a new market or team
- Any change to what it may read, call or write, or what it may look up

A new model is re-tested against the test set before the agent keeps its grade. If it fails, back to Observe.

Report demotions beside promotions.
