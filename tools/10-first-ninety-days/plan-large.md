# The first ninety days · large business

Two permanent people by month six, not thirty. One champion in each business unit, chosen by that unit's own leader, with a dotted line to the centre.

## Month one

- [ ] Census of every platform and agent in use (it will be longer than anyone expects)
- [ ] Start the one-client test: one client's history, brought together from every system it's in, inside eight weeks
- [ ] Baseline for the first workflow, agreed with finance
- [ ] No platform spend, no vendor contract, no headcount request

## Month two

- [ ] Data view over existing systems, only what the first workflow needs
- [ ] First agent built to a reusable template, at Observe from day one
- [ ] The ten-field agent standard published
- [ ] Register live and visible to business-unit heads

## Month three

- [ ] Promotion to Recommend where the numbers support it, nowhere else
- [ ] Second and third markets configured rather than rebuilt
- [ ] Notes on how to repeat it, written from what happened

## Published along the way

The agent standard · the register · the gate criteria · the baseline · the first scorecard · the first kill list

The agent standard is the ten-field register page (tool 7), agreed as the rule every agent must meet. The scorecard is the two columns (tool 4), with each agent's grade and latest test-set score beside them.
