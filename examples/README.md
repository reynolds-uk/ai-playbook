# Examples

What the plugin writes, before you install it. Each page was written by a skill in a test run on 28 September 2026, with a second model playing a realistic user for a fictional business. The people and the figures are invented for the test; the pages are as the skills wrote them.

| Page | Skill | The business |
| --- | --- | --- |
| [leader-check.md](leader-check.md) | `leader-check` | A 220-person, PE-backed accountancy and advisory firm, with an invoice agent nobody checks |
| [where-the-time-goes.md](where-the-time-goes.md) | `where-the-time-goes` | A 60-person insurance broker's commercial renewals: 90 minutes of work in 11 days |
| [register.md](register.md) | `agent-register` | A 150-person logistics business with four AI tools |
| [two-columns.md](two-columns.md) and [two-columns.csv](two-columns.csv) | `two-columns` | The same logistics business's Q3 savings claims |

In your own use, these land in an `ai-playbook/` folder alongside `decisions.md`, the record of what was decided, by whom and on what evidence.
