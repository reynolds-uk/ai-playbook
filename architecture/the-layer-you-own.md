# The layer you own

How I'd put AI into a services business. The reasoning is in [The layer you own](https://ai.valuecreator.io/read/the-layer-you-own), and the picture is free to use from [ai.valuecreator.io/pictures](https://ai.valuecreator.io/pictures#services-architecture).

## In plain terms

Every vendor will sell you a task agent. If every competitor can buy the same agents, the advantage is in what they're connected to. Buy the models, route the work, and own a small layer underneath: one connected picture of your clients and decisions, a register of every agent, and a test set made from your own cases. The decision a client relies on stays with a named person.

## The four layers

| Layer | What it is | Buy or own |
| --- | --- | --- |
| **Buy** | The models: frontier, small and local. Swap them when something better or cheaper passes your tests | Buy |
| **Route** | Each step to the cheapest model that passes. Hard judgement to the best. Data rules first | Own the rules |
| **Run** | Agents, each built once as a template and deployed as numbered versions (for example intake, research, drafting, quality check, client reporting), all on the register | Build or buy the agents, own the register |
| **Own** | The knowledge graph (clients, work, people, rules, documents, decisions), the register and the test set | Own |

Underneath: your systems of record stay where they are, connected rather than replaced.

## Always a person

Taking on a new client, signing off advice, pricing a piece of work, anything a client will rely on without checking it themselves. The machine prepares. The professional decides.

## Build once, configure, promote independently

Build each workflow agent once. Put the differences between teams or countries in the knowledge graph as configuration. Let each deployment earn its own grade, so the same agent can act on its own in one place while it's still recommending in another.

## Where to start

One workflow, one team, end to end. If you can bring one client's history together from the systems it's scattered across inside eight weeks, the graph is real. Put one agent on the register at Observe, publish the criteria it has to meet, measure before and after, and decide in the room whether to carry on.
